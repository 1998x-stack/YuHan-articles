# 文章总库

韩愈式古文论说文按 **八大主题／子目／独立篇名目录** 分类。无正文的子目均已建立可浏览的 README 占位，不虚构文章。

## 八大分类

- [01-史论与人物](01-史论与人物/README.md)：历史事件、人物评价与制度沿革。
- [02-制度与治理](02-制度与治理/README.md)：公共制度、监督治理、组织权责与社会保障。
- [03-经济与产业](03-经济与产业/README.md)：经济增长、企业经营、财政与收入分配。
- [04-宗教与风俗](04-宗教与风俗/README.md)：宗教组织、信仰实践、民间风俗与观念。
- [05-社会与人情](05-社会与人情/README.md)：社会心理、职业伦理、世道人情与家庭生活。
- [06-思想与学术](06-思想与学术/README.md)：哲学、教育、知识论与学术思想。
- [07-文论与写作](07-文论与写作/README.md)：古文理论、论辩写作及篇章评点。
- [08-杂说与辨析](08-杂说与辨析/README.md)：不宜归入其他专题而有论旨的短文。
