## 路径与出版规则

- 一篇一目录：`articles/XX-主题/子目/篇名/`，目录需有 `README.md`、`article.json` 与唯一 Markdown 正文。
- Markdown 为唯一正文来源；同名 `.docx` 和 `.pdf` 由 `scripts/build_articles.py` 和 GitHub Actions 统一生成。源文件若名为 `篇名_润色稿.md`，衍生文件保持同基名。
- 仅有分类说明的 `README.md` 才是待收录目录，不能在总目录中虚构作品。
- 跨主题的文章只归档一处，其他分类可在索引交叉引用，避免多份正文漂移。
- 新增篇目须更新 `article.json`、所属子目和部类的 `README.md`、`CATALOG.md`。
