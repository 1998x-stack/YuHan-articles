## 组织约定

每篇文章一目录，目录含 `article.json`、正文 `篇名.md`、排印 `篇名.docx` 与 `篇名.pdf`。Markdown 为唯一正文源，DOCX/PDF 是衍生出版物。不要同时独立编辑三份正文；修改正文后运行 `python scripts/build_articles.py` 统一再生成。

空分类以 `README.md` 保留，**不使用无意义的 .gitkeep**；新增分类及单篇后同步更新 `CATALOG.md`。详见 [出版规范](../docs/article-archive-conventions.md)。
