# 文章库分类体系与档案结构

## 分类目的

采用稳定的八大主题与可扩展子目，以议论对象与核心问题决定归属，而不是按原文载体、是否为时事或文件格式混合分组。

## 部类与子目

### 01-史论与人物

史实与史论、人物功过、古代制度沿革。

- **史事辨**：辨别史料与传说，揭示事件的成因、过程与解释边界。
- **人物论**：考察人物言行、历史处境、功过与制度约束。
- **制度史论**：讨论历代制度运行及其成败得失。

### 02-制度与治理

监察执纪、公共政策、组织运行与权责。

- **纪检监察**：执纪监督、调查程序、证据、权责与公私界限。
- **公共治理**：公共政策、公共服务、制度执行与治理效果。
- **组织管理**：企业和公共组织的权责配置、管理与监督。
- **法治与权责**：法律程序、权力约束、公私责任及合法性辨析。
- **法治与程序**：刑事司法、证据规则、量刑说理与审判程序；既有子目，不与其他法律类重复建稿。

### 03-经济与产业

增长、产业、经营、财税与收入分配。

- **宏观经济**：生产率、增长、国际比较和宏观政策。
- **产业发展**：产业结构、制造业、产业链和技术变迁。
- **企业经营**：企业经营、用工、激励、成本与竞争。
- **财政与分配**：财政、税制、公共收支、社会保障及分配。

### 04-宗教与风俗

宗教组织、宗教治理、民俗与社会观念。

- **宗教治理**：宗教场所的财务、治理、信任与法律边界。
- **风俗与民俗**：民间习俗、祭祀、传说及其社会机制。
- **观念辨析**：信仰与民俗中的名实、恐惧、利益和群体行为。

### 05-社会与人情

职业伦理、群体行为与日常社会关系。

- **职业伦理**：劳动处境、职业角色、操守与激励。
- **人情世故**：日常交往、礼俗、世态与利益关系。
- **群体行为**：群体心理、社会期待与公共舆论。\n- **修身与治事**：时间与精力安排、持续学习、任务衔接与个人处世方法。

### 06-思想与学术

哲学义理、教育与学术方法。

- **哲学思辨**：价值、人生、道德与思想命题的论辩。
- **教育与师道**：教学、学习、师生关系与教育治理。
- **知识论**：证据、推理、认识的限度与学术方法。

### 07-文论与写作

韩愈古文、论辩技法与文章评点。

- **古文论**：唐宋古文、散体传统与文学思想。
- **写作方法**：立论、结构、用证、反诘与句法。
- **篇章评点**：作品评析、文本比较与修改实录。

### 08-杂说与辨析

跨领域的短辨、问答与杂论。

- **时事杂说**：不便归入专类的时事观察与简论。
- **短辨**：针对单一命题、谬误或概念的短篇辩难。
- **笔谈**：问答、随笔与议论札记。

## 单篇目录规范

~~~text
articles/
  04-宗教与风俗/
    宗教治理/
      README.md
      原寺观财弊论/
        README.md
        article.json
        原寺观财弊论_润色稿.md
        原寺观财弊论_润色稿.docx
        原寺观财弊论_润色稿.pdf
~~~

Git 不跟踪空文件夹，因此用有实际说明的 `README.md` 作为子目占位；不制造虚假的文章正文。文章只按主题归档一次，不把 Markdown、Word、PDF 分散到各自格式目录。文件名保留中文篇名与必要版本名，同一个来源文件三个格式使用相同基名。

## 收录流程

1. 判定主论题，选择唯一部类与子目；若现有子目不适合，先建立新的子目 README，并更新分类导航。
2. 复制 `_templates/article/` 到文章目录，填写 `article.json` 的 `title`、`manuscript`、`category`、`subcategory`、`date`、`status`、`topics`。
3. 将完整文章置于 Markdown，事实来源以文末注释列出；标明传闻与推断，避免当作确证史实。
4. 同步更新单篇 README、子目 README、部类 README 和 `CATALOG.md`；由自动化出版生成 Word/PDF。
5. 检查生成物文件名、链接、中文字体与参考资料。文章内容改动只改 Markdown，不手工分别更改二进制衍生文件。

## 出版状态

- `draft`：草稿，不列入“已发表”目录。
- `review`：正在核对证据及文体，不列入“已发表”目录。
- `published`：已发布正文，出版流程应同时提供 DOCX/PDF。
