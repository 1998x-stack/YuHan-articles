# 文章分类体系

此库按**主要论证对象**分类；一篇文章仅有一处正文，跨领域主题写在 `article.json.topics`。

## 八大部类与预留子目

- **01-史论与人物**（历史事件、人物评价与制度沿革）：史事辨、人物论、制度史论。
- **02-制度与治理**（公共制度、监督治理、组织权责与社会保障）：纪检监察、公共治理、组织管理、社会保障、法治与程序。
- **03-经济与产业**（经济增长、企业经营、财政与收入分配）：宏观经济、产业发展、企业经营、收入分配。
- **04-宗教与风俗**（宗教组织、信仰实践、民间风俗与观念）：宗教治理、风俗与民俗、观念辨析。
- **05-社会与人情**（社会心理、职业伦理、世道人情与家庭生活）：职业伦理、人情世故、群体行为、家庭与代际。
- **06-思想与学术**（哲学、教育、知识论与学术思想）：哲学思辨、教育与师道、知识论。
- **07-文论与写作**（古文理论、论辩写作及篇章评点）：古文论、写作方法、篇章评点。
- **08-杂说与辨析**（不宜归入其他专题而有论旨的短文）：时事杂说、短辨、笔谈。

## 归类规则

- 对历史叙事和古代制度作辨析，归 **01 史论与人物**。
- 对现实公共制度、监管、养老金等规则作论辩，归 **02 制度与治理**；本篇《原养老公平论》归其 **社会保障** 子目。
- 以产业与经济分配为主要对象，归 **03 经济与产业**；以家庭与代际关系为主要对象，归 **05 社会与人情**，不因为涉及养老就统一归一类。
- 宗教财务与寺观管理，归 **04 宗教与风俗／宗教治理**。
- **08 杂说与辨析** 为最后选项，不能仅因篇名有“辨”就归此类。

- 对刑事判决、死刑适用、司法程序与证据规则之议论，归 **02 制度与治理／法治与程序**，如《徽剑案刑罚辨》。

## 单篇目录标准

```text
articles/02-制度与治理/社会保障/原养老公平论/
├── README.md                # 摘要、导航与事实边界
├── article.json             # 标题、分类、标签、正文文件名
├── 原养老公平论.md           # 唯一正文源
├── 原养老公平论.docx         # 自动出版的 Word
└── 原养老公平论.pdf          # 自动出版的 PDF
```

空子目使用具有分类说明的 `README.md` 保留目录，不用 `.gitkeep`，亦不伪造文章占位。新增作品要更新子目 README、部类 README 与 [`CATALOG.md`](CATALOG.md)，所有正文修改须由 Markdown 重新生成 Word/PDF。

详见 [归档出版规范](../docs/article-archive-conventions.md)。
