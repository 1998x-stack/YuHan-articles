# 文章主题分类体系 · Taxonomy

此库按**议论对象与主要论证问题**分类，而不是按“原、论、说、辨”文体分类。每篇文章只有**一个主目录**，跨领域关联通过 `article.json.topics` 表达；韩愈本人真作应在 [classics/](../classics/README.md)，不进入这里。

## 八大部类（稳定）

| 部类 | 归档重点 | 代表子目（不是完整目录清单） |
| --- | --- | --- |
| 01-史论与人物 | 历史事件、人物及制度沿革的辨析 | 史事辨、人物论、制度史论 |
| 02-制度与治理 | 治理机制、责任、公正、保障和监督 | 纪检监察、组织管理、公共治理、社会保障、法治与程序 |
| 03-经济与产业 | 增长、产业、财赋、分配与企业经营 | 增长与分配、宏观经济、产业发展、收入分配、财富管理与传承 |
| 04-宗教与风俗 | 宗教组织、信俗、公共生活与名实 | 宗教治理、风俗与民俗、观念辨析 |
| 05-社会与人情 | 人情世故、城乡、劳动、教育与家庭 | 人情世故、城乡与民生、教育与阶层、修身与治事 |
| 06-思想与学术 | 知识、哲学、教育与思想史 | 哲学思辨、教育与师道、知识论 |
| 07-文论与写作 | 古文论辩、文章章法、文学评点 | 古文论、写作方法、篇章评点 |
| 08-杂说与辨析 | 尚不能稳妥归类的独立短辨 | 时事杂说、短辨、笔谈 |

以上子目是**推荐入口和示例**，不等于全部已经建立的历史目录；现存真实子目以 Git 目录和各自 README 为准，不因文档摘要少列就随意删除。

## 判别规则

- 史料与传说的真实性、人物历史处境为主要问题，归 01；即使涉及民俗也不自动迁往 04。
- 公共政策、养老金公平、执法程序与组织责任归 02；如果文章核心是个人家庭处境，则按题旨考虑 05。
- 经济增长、后发优势、财政、收入、产业结构归 03；以家族信托、资产保护、财富传承及受托制度为重心的文章，归 03 下的“财富管理与传承”。
- 宗教活动场所财务与公共治理归 04 的宗教治理；不能只因文体带“辨”而归 08。
- 日常社交、时间管理、城乡生活、教育机会与社会心理归 05。
- 抽象认识方法、师道、学术和知识论归 06；文学技法、古文评点归 07。
- 只有其他主题均不适用时才归 08。短篇也可以是历史或经济评论，不能仅凭篇幅改变归类。

## 迁移与维护

项目历史上保留了若干相近名称的子目，例如`史事辨／史事辨析`、`组织管理／公共治理`与`宗教组织／宗教治理`。名称近似不代表内容完全重合。若要合并：先查已有文章、源码路径、README 交叉链接与 Pages URL；提出旧地址兼容计划；再修改文件和导航。严禁在没有链接迁移计划的情况下批量移动已有文章。

空子目保留有解释的 README，不为凑数创建空文章。新增真实子目先复用已有领域，确有必要再建立说明其**范围、边界、所依一级部类**的 README，并更新父级分类导航。
