## 唯一主分类与交叉索引

1. 根据文章的**核心问题和主要证据**选择一个主分类，而不是依标题字面或某个关键词机械归档。
2. 一篇文章仅存一份正文和一组衍生格式；其他相关分类以 README 中的链接交叉引用。
3. 例如《河伯娶妇辨》主要围绕西门豹治邺的史事展开，主目录为 `01-史论与人物/史事辨`，另在 `04-宗教与风俗/风俗与民俗` 建立交叉索引。
4. 题目涉及多个方向时先明确中心论旨；无对应子目再扩展子目，并同步更新本页和分类导航。

## 单篇目录规范

```text
articles/01-史论与人物/史事辨/河伯娶妇辨/
├── README.md            # 论旨、史料边界、关联主题及下载链接
├── article.json         # 机器可读元数据
├── 河伯娶妇辨.md         # 唯一可编辑正文
├── 河伯娶妇辨.docx       # 自动派生的排印版本
└── 河伯娶妇辨.pdf        # 自动派生的排印版本
```

## 收录与发布规则

- `README.md`：每个分类、子目与篇章均提供明确入口；占位目录标注“待收录”，不可称为已出版。
- `article.json`：至少有 `title`、`manuscript`、`category`、`subcategory`、`date`、`status`、`topics`。
- `篇名.md`：正文标题与元数据一致；修改后同步生成另外两种格式。
- `articles/CATALOG.md`：只列真实发表的文章，不列空占位。
- `docs/article-archive-conventions.md`：归档及证据边界的正式规范。
- 新文章先复制 `articles/_templates/article/` 模板，再按主题归档；不要单独为 `.md`、`.docx`、`.pdf` 建格式目录。

## 扩展预留

现有 8 个一级主题、24 个规划子目（含已有的“纪检监察”子目）。新增专题时优先按内容增设二级子目，避免扩大一级分类造成检索分裂。
