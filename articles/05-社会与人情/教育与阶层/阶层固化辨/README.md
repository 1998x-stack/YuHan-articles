# 阶层固化辨

**篇旨：** 从《蜗居》所呈现的购房焦虑、求援机会与权力落差入手，辨勤惰之说与财富分配之末；以“关津”为喻，推究住房、渠道、信用、资产、牌照与交游如何影响机会，又如何经资本积累和代际传递加固差距。辨明产权与正常交易的正当性，不以个别戏剧情节证明社会完全封闭，最终论机会公平、制度约束与社会流动之道。

## 事实依据与论证边界

- **电视剧而非史实：** 《蜗居》的故事城市名为“江州”，虽然创作背景与上海有关，但其人物、案件和转圜方式都属于剧情，不能用来统计现实阶层的开放程度。[爱奇艺剧情速看](https://www.iqiyi.com/a_mza85epzu9.html)。
- **“一通电话即可放人”的简化问题：** 第21—25集情节亦涉及律师介入和关系运作；既不能假定苏淳所涉案情“未造成损失”，也不能据此对真实司法系统作出定量判断。[新浪娱乐分集剧情](https://ent.sina.com.cn/v/2009-11-13/10472768546.shtml)。
- **经济机制有条件：** 财产收益、经营渠道、许可牌照与不公平的权力寻租须分别考察；拥有资产不天然构成剥削，社会流动不可能由任何单一要素完全解释。
- **跨国文献边界：** [OECD《Employment Outlook 2025》](https://www.oecd.org/en/publications/oecd-employment-outlook-2025_194a947b-en/full-report/setting-the-scene-demographic-change-economic-growth-and-intergenerational-inequalities_9d481169.html)及[2026年代际流动报告](https://www.oecd.org/content/dam/oecd/en/publications/reports/2026/03/intergenerational-social-mobility-across-oecd-countries_c45c6be5/6d76ec2a-en.pdf)提供理解财富与住房传递的比较研究，不直接对应中国总体。
- **中国经验研究：** [郝晓婧（2023）](https://gcxb.gufe.edu.cn/CN/Y2023/V41/I01/1)与[汪小芹（2025）](https://jnxb.jnu.edu.cn/skb/CN/Y2025/V47/I8/172)提示不同维度、指标和世代的流动性可能并不一致，不能作“阶层完全冻结”的绝对判断。
