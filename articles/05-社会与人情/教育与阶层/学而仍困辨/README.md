# 学而仍困辨

**篇旨：** 以“送走廉价农民工，迎来廉价大学生”的流行叹语为端，辨其事实之未尽确与情理之可深究。论贫家举力供学、教育回报不确定、所学与就业需求失配，以及劳动价值不应仅以供求简化；所忧在两代勤劳而困境或相续，不在贬低任何职业。

## 事实依据与边界

- **起始话语：** 用户提供的网络短句，为修辞性社会评论，不能当作全国劳动市场的事实描述。
- **农民工仍在从业：** [国家统计局《2025年农民工监测调查报告》](https://www.stats.gov.cn/sj/zxfb/202604/t20260430_1963472.html)，2025年总量30115万人、月均收入5075元；统计对象不是高校毕业生总体。
- **毕业生规模：** [新华社据教育部消息](https://www.xinhuanet.com/20251120/ead0f25dff2948dfa7f01fa78f207882/c.html)，2026届普通高校毕业生预计1270万人；此为供给规模，不是失业率或薪资数据。
- **论断边界：** “多数大学生由农民工供出”“大学生普遍比农民工更廉价”均无足够证据支持。文中“或既卒业……”“或虽得职……”是对可能处境的分类陈述，非代表性抽样结论。
