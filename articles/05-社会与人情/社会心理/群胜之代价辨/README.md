# 群胜之代价辨

**归档：** [社会与人情](../../README.md) / [社会心理](../README.md)  
**文类：** 现代社会议论韩愈式古文（非韩愈本人作品）  
**发表：** 2026-11-09

## 论旨

以作者壬寅年在沪封控期间的亲历，辨“集体之胜”与个体代价。文章保留作者对五日备粮、4月18日首次领取社区食物、求助无应、饥迫欲闯关等个人记忆；论证不以此一例否定公共卫生措施，而追问以集体目标为名时，供给保障、求助渠道、风险分担与责任归属是否相称。结论是：共同承担可以有，不能把集体之名变成个人无告的理由。

## 证据边界与校核

- **个人经历：** 备粮五日、4月18日首次收到社区食物、菜品难购、报警后被指向社区而电话未通、曾考虑闯关求食，均为作者第一人称陈述。外部资料只能说明当时上海普遍存在供应短缺背景，不能替代或独立验证该社区个案。
- **初期时限与供应困难：** 美联社于2022-04-07报道，部分居民称最初被告知封控将持续四日，线上食品供应售罄，部分家庭难以取得米肉等食物。该报道为同期背景材料。
- **计划与实际时长：** Fei Chen于2026年发表于《International Journal of Asian Studies》的研究，基于18名亲历者访谈，记载上海最初宣布的封控计划为3月28日至4月5日、实际多数居民受限逾两月，并讨论配送受限与供应短缺。此为研究者访谈样本与分析，不应与作者个人细节混为一谈。
- **解封时间：** 路透社2022-05-30报道，上海拟自6月1日起解除为期两月的封控，并提到居民取食困难及收入损失。
- “群体免疫”一语按原作者对岁末政策转向的个人概括保留，不据此声称其为正式政策文件名称。
- 文中对个人经历的记述不扩张为全体居民的同一经历，也不把防疫目标本身判为虚假；批评对象在于集体目标与个体生存保障、决策责任及代价分担之间的失衡。
