# 长甲离婚辨

**归档：** [社会与人情](../../README.md) / [社会心理](../README.md)  
**文类：** 现代社会议论韩愈式古文（非韩愈本人作品）  
**发表：** 2026-11-17

## 论旨

以2026年11月网络流传的「长指甲离婚定律」为论辩对象，区别网上晒离婚证者的外观、所有离婚者的外观与长美甲者的离婚风险三个不同问题。文章承认长美甲可能妨碍部分家务，继而检验「不便某务—不治家事—不事生业—必致离婚」的跳跃，并论证婚姻稳定涉及家务分担、彼此承认、责任与信任，而非仅凭个人妆饰作道德判断。

## 证据边界与校核

- **传播现象：** 2026年11月中旬的微博转载与播客讨论证明此说在网络传播；未能确认首创者的可信原始发布记录，因此不写死其发明人、视频数量或传播规模。
- **不是统计定律：** 流传的晒证截图没有经验证的代表性样本、对照组、甲长判定标准和婚姻时间顺序。文章举「离者十人、其中七人长甲；未离者百人、其中八十人长甲」为**明确假设**，仅说明条件概率不可倒置，非现实调查数字。
- **美甲与家务：** 指甲长度确可能影响特定手工任务，但不能由此识别某人就业、家庭劳动、资财分担与责任履行。相关例子均为可行情境，不是特定真实人物案卷。
- **2020年中国妇女社会地位调查：** 全国妇联与国家统计局联合调查的公开数据指出，在业女性工作日平均有酬劳动495分钟、家庭照护与家务154分钟，后一项约为男性的2倍。该数字只适用于所述调查对象与时点，不能代替对美甲群体的研究。
- **学术旁证：** 瑞典研究将夫妻双方家务自述与后续关系稳定性相对照，发现家务承担失衡以及伴侣贬低劳动贡献与较低关系质量、较高解体风险相关。此属特定地区的观察关联，不能推称「家务失衡必然导致离婚」，更不能当作长指甲效应。
- **时序与动机：** 「离后始修甲」为反向因果的可能情境，不是对网上持证女子的事实断言。本文不因持证或离异本身判定任何人有过。
