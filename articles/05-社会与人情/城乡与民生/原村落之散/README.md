# 原村落之散

**论旨：** 从晋陕部分山村人口稀疏、班车减少、乡集社交、独居老人及山地撂荒等见闻发端，辨析“乡村空心化”与“全国农村尽成无人区”之异；指出人口迁移与服务网络退缩的循环，并将村庄存续的标准由建筑、行政牌额推进到就业、交通、医疗、教育、照护与社会联系。

## 材料来源与核查边界

- **原始素材：** 用户提供的两则关于农村空心化的网络见闻；其中[晋陕山地调查叙述](https://www.zhihu.com/question/367018216/answer/2032005085262239313)可定位到用户提供的原文网址。涉及匿名乡镇人口、车资、亩产、丧礼的数字和故事，**均属原作者报告的地方材料，未完成独立田野核验**，不得上升为全国性测量结果。
- **人口口径：** [国家统计局《2025年国民经济和社会发展统计公报》](https://www.stats.gov.cn/sj/zxfb/202602/t20260228_1962662.html)，2025年末乡村常住人口45109万人、常住人口城镇化率67.89%。
- **乡村老龄化：** [《2020年度国家老龄事业发展公报》](https://www.nhc.gov.cn/lljks/c100157/202110/b365898ae2a4406d91e1b1ecd10ca911.shtml)，依据第七次人口普查，乡村65岁及以上人口占比17.72%。
- **农村客运：** [交通运输部《农村道路客运运营服务指南（试行）》](https://xxgk.mot.gov.cn/jigou/ysfws/202406/t20240628_4143359.html)，鼓励区域经营、预约响应及客货邮融合。
- **土地耕作：** [农业农村部撂荒地利用指导意见](https://jhs.moa.gov.cn/jjyx/202101/t20210122_6360367.htm)，因地制宜分类复耕，不支持“撂荒必不可逆”的绝对说法。
- **国际参照：** [日本国土交通省、总务省2025年发布的聚落调查](https://www.mlit.go.jp/report/press/kokudoseisaku03_hh_000263.html)，截至2024年4月的指定偏远地区数据，**非全日本村庄总量**；老龄人口过半不等同于立即无人化。
- **政策依据：** [2026年中央一号文件](https://www.mee.gov.cn/zcwj/zyygwj/202602/t20260203_1143548.shtml)，强调稳定农村客运、保留必要的小规模学校与探访关爱特殊困难老人。
