## 核验与证据边界

本文根据用户提供的多篇时间管理评论重构，人物事迹及一般性论断另行核验。正文为独立可读的古文，来源集中存于此页。

- [电子科技大学校友资料](https://www.newsdata.uestc.edu.cn/?Id=94666&n=UestcNews.Front.DocumentV2.ArticlePage)：彭志辉早年专业、学习及机器人事业。
- [《晚点》彭志辉访谈（转载）](https://www.bianews.com/news/details?id=193697)：本人陈述任务按优先级切换、分时专注，一次仅做一事；另述个人休息习惯。
- [澎湃新闻（2021）](https://www.thepaper.cn/newsDetail_forward_13286970)：其业余作品与作息自述。
- [世界卫生组织：身体活动](https://www.who.int/initiatives/behealthy/physical-activity/)；[美国 CDC：睡眠](https://www.cdc.gov/sleep/about/)：规律活动及休息值得重视，不能推论为避免未来疾病及医疗支出的保证。
- [Gollwitzer & Sheeran（2006）](https://doi.org/10.1016/S0065-2601(06)38002-1)：行动意图与目标达成的元分析。
- [Trafton 等（2003）](https://doi.org/10.1016/S1071-5819(03)00023-5)：任务中断后恢复的相关研究。
- [Howard 等（2021）](https://pubmed.ncbi.nlm.nih.gov/33593153/)：学习动机与坚持、学习成果的元分析。

原文“砍掉八成事情”“大病必吞十余年积蓄”等为论者修辞，并非经过核实的普遍统计事实。彭志辉“必然拥有某种连续项目文档”也是评论者推断，访谈并未证实；Excel、电子日历、Word 的做法来自另一位论者的自述，不能混称彭氏方法。
