# 革命与易代辨

**篇旨：** 从“易主”与“更制”的不同出发，考察中国近代革命如何由土地之争、军政组织，转入国家性质、行政体系与经济秩序的制度建设。反对把中国革命等同于古代改朝换代，也反对凭纲领与口号断言一切旧弊已消。

## 主要参核史料

1. [《中国土地法大纲》（1947年10月10日）](https://www.chnmuseum.cn/zp/zpml/gmww/202112/t20211214_253215.shtml)，中国国家博物馆馆藏介绍。确认法大纲的颁行时间及耕者有其田的基本主张。
2. [《论联合政府》（1945年4月24日）](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450424.htm)，毛泽东在中共七大的政治报告；明确其发表于抗战胜利之前，且提出建立民主联合政府。
3. [《中国人民解放军宣言》（1947年10月10日）](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19471010.htm)；宣言在“打倒蒋介石”之外仍有“组织民主联合政府”目标。
4. [《关于目前党的政策中的几个重要问题》（1948年1月18日）](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19480118.htm)；核对新民主主义政权、人民代表大会、联合中农及保护中小工商业等主张。
5. [1929年古田会议所作决议的史料说明](https://www.dswxyjy.org.cn/GB/434461/434473/435006/index.html)，中央党史和文献研究院；“单纯军事观点”“流寇思想”等批评是指当时红军内部问题，并非毛泽东于延安专为全部古代起义所作的总论。
6. [美国国务院《美国对外关系文件》1947年卷：魏德迈调查团任务指令](https://history.state.gov/historicaldocuments/frus1947v07/d536)，美国国务院历史办公室；任务是考察形势及可能援助，并无充分资料支持原口述中“既已确定八处基地及整套主权出让条约”的断言。
7. [《陈云与解放战争时期的东北财经工作》](https://www.dswxyjy.org.cn/n1/2023/0110/c423731-32603549.html)，中央党史和文献研究院。
8. [《解放战争时期东北解放区货币统一的历史考察》](https://ccss.cbpt.cnki.net/portal/journal/portal/client/paper/41446bc39f86a2c346f789fb93fc7e46)，李晔晔、王校峰，《长春师范大学学报》2026年第7期。说明东北多币并行、东北银行法币及地方流通券的整理过程。
9. [《共同纲领》的制定](https://www.dswxyjy.org.cn/n/2012/0920/c244520-19065375.html)，中央党史和文献研究院。
10. [1949年《中国人民政治协商会议共同纲领》](https://www.chnmuseum.cn/zp/zpml/gmww/202104/t20210406_249569.shtml)，中国国家博物馆馆藏介绍。

## 史料与论证边界

- 原始口述把1947年《解放军宣言》说成已放弃联合政府，但宣言正文仍提出此目标，本文予以更正；“人民民主专政”的完整国家制度表述也应同1948年新民主主义政权纲领及1949年《共同纲领》区别。
- 原稿关于“卫立煌发行紫色新货币”、法币专项入股工厂、国民党军官指定金融套利流程、特定物价涨幅、群众委员会统一选举限制等细节，未获得充分可交叉验证的资料，本文**不将其写为确定史实**。
- 战后经济波动、政治参与与政权建设极其复杂，本文着重论证“夺权不等于治国”，不以纲领文本本身证明理想制度已完全实施，亦不以单一外因解释内战全部结果。
