# 欧陆争衡与东北兵势辨

**篇旨：** 考察1945—1949年西欧左翼政治兴起、马歇尔计划、柏林危机与中国东北战局之间的联系，以史料辨析“欧陆之争直接决定中国内战结局”的单线因果叙述，区分外部牵制与中国国内的战争、治理及组织因素。

## 史料依据与编辑边界

正文文末附八组来源，含法国国民议会、美国国务院历史办公室、美国国家档案馆、德国联邦档案馆、1945年《雅尔塔协定》及学术研究。特别区分：

- 1947年5月法国共产党部长被免职，早于1947年6月提出的马歇尔计划；
- 意大利共产党在1948年选举失利，但仍在议会占有席位；
- 《雅尔塔协定》涉及东北港口和铁路权益，亦明示中国仍保有东北主权；
- 柏林危机与辽沈战役的时间相近，不足以独立证明二者有直接协同行动。
