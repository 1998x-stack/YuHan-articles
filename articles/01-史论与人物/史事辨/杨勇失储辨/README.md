# 杨勇失储辨

**论旨：** 由杨勇冷落元妃、宠信云昭训之事，辨联姻政治、嫡庶秩序、帝后家法与储位争夺之间的因果；既考其失礼致隙，也考杨广、杨素的构陷，不以史家记载的怀疑冒充毒杀与血统疑案的定论。

## 史料与辨疑

一、主要依据《隋书》卷一《高祖纪上》、卷四十五《房陵王勇传》、卷五十《元孝矩传》，元妃父名依原史作**元孝矩**，不作“元孝炬”。

二、元妃“心疾，二日而薨”与独孤后怀疑投药是不同层级的记载；高祖怀疑杨俨血统、述东宫失礼诸事，亦与已获独立证实的事实不同。本文保留此区分。

三、关陇集团为现代史学分析概念，集团内部构成与分期有学术争论；不能说元氏为全部六镇军人共同起源，更不能仅凭联姻认定隋朝法统全系于元氏。

四、杨勇有参决政事、谏徙民等正面事迹；杨广、杨素构罪见史书记载，不应以“宠妾”一因抹去储争的权力操作。
