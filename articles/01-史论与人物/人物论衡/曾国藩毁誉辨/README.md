## 尚待证实或不予采信的推断

原文将若干学者、小说家、研究机构的出版与节目活动，连为暗中统一策划的“洗白产业链”，并以家庭关系、族属和地域关系推论政治动机。现有证据可证明多种作品与传播活动在时间上相近，却**不足证明彼此接受统一指挥或资助**。故正文将其改写为不同媒介相互强化的传播机制，而非坐实阴谋。

源文所谓曾国藩“几十万条人命”没有给出足以核验的统计口径，也未清楚区分清军奏报、日记见闻和后人估算；本文不将此数字作为确定结论。同理，不以特定家族、民族身份推断学术观点真伪，不引未经证实的清初文字狱轶闻。
