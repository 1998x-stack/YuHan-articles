# 务本辨

**论旨：** 事有本末，人力有穷。论职场中无限承责与形式主义之弊，辨清无效繁务和必要复核之别，进而追究考核激励、权责分配及组织改进之道。

**归档：** [制度与治理](../../README.md)／[组织管理](../README.md)；**日期：** 2026-11-06。本文是参照韩愈论辩章法创作的新古文，并非韩愈原作。

**三种格式：** [Markdown](务本辨.md) · [DOCX](务本辨.docx) · [PDF](务本辨.pdf)

## 原文范围与证据边界

主稿依据用户提供的知乎文章「系统冗余」一文重构，保留了服侍上级的会议见闻、约一千万元预算材料、二十小时编写与二十秒翻阅的对照。以上均为原作者自述，未作独立事实查证，不能据以推断所有项目材料无用；附在原帖之后的其他网友回答不与主稿混为同一作者经历。

本篇作出两项辨析：其一，**目标置换**说明规则与文件可能由手段变为目的；其二，**组织冗余并非必然浪费**，必要的审计、复核、备份和风险缓冲应同形式性重复劳动区分。文中提及公开通报的考核负担案例，属独立核验的补充事实。

## 调查依据

- [Robert K. Merton, *Bureaucratic Structure and Personality*（1940）](https://academic.oup.com/sf/article-abstract/18/4/560/1990520)；[明尼苏达大学所载选文](https://www.d.umn.edu/cla/faculty/jhamlin/4111/Merton/Social%20Theory%20and%20Social%20Structure%20Bureaucratic%20Structure%20a.htm)：论由守规则变为以规则为目的的目标置换。
- [*Distinguishing Useful and Wasteful Slack*, Operations Research](https://doi.org/10.1287/opre.2022.2415)：指出组织中的富余资源既可能发挥缓冲价值，也可能形成无效成本，二者不宜混同。
- [中央层面公开通报整治形式主义为基层减负典型问题（2025-07-24）](https://www.samr.gov.cn/jjz/jzcm/art/2025/art_acea230ad6044c1c88f13253c9dcc635.html)：载黑龙江绥化部分考核指标繁杂、索取台账和会议照片等佐证、加重基层负担。
- [《整治形式主义为基层减负若干规定》](https://www.mee.gov.cn/zcwj/zyygwj/202508/t20250813_1125346.shtml)：涉及精简文件、规范考核、明确基层权责等制度措施。
