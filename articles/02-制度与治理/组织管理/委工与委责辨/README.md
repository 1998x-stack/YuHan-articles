# 委工与委责辨

**论旨：** 造船及其他复杂制造业可以依行业周期、专业分工运用外协，但不能借分包之名放弃统一协调、安全培训、质量追溯及真实成本核算。辨“分工”与“卸责”之异，兼论考核指标可能引起的名实错置。

## 核查范围与证据边界

本文根据用户提供的网络议论重构论证。原帖所称江南造船“参保约4500人、厂内约3万人”不是同口径核实数据。公开信息平台显示该企业2025年报参保人数约4330人，而2023—2024年的企业介绍与报道指员工、产业工人约2万人，其中劳务人员比例较高。**法人参保人数不能与不同时点、不同雇主的厂内用工人数直接相减，也不能由此断定外协人员未缴社保。**

原帖关于焊工技能退化、返工及安全事故增多、某集团用人均产值决定工资总额并诱导外包的说法，尚未取得相应厂区质量统计、事故调查或考核原件证实。正文将其作为需要核实的争论焦点与条件假设，未将其写成已证实事实。

外包存在产业周期和专业分工方面的合理性；本文批评的是责任链断裂与短期指标掩蔽长期成本的制度风险，而不是概称外包必有事故，也不将美国波音事件直接等同于中国船厂。
