## 论旨

以韩国女性服兵役讨论再起为发端，辨析群体平均生理差异与个体适任能力、国家兵役义务与个人生育自主之间的界限。文章承认男女群体平均体能存在差异，也正面呈现韩国宪法法院2023年维持男性征兵制度合宪的理由；但指出合宪不等于制度永不可变，行政便利亦不足以成为永久以性别分配强制义务的唯一依据。

文章主张：兵役制度应以国家实际防卫需求、岗位能力、个体健康及可检验标准为据；同一岗位应有一致的任务标准，不同岗位依其职能设定要求。若讨论扩大征兵，须同时处理待遇、替代役、孕产保障、军中安全与申诉机制；若兵力不足源于组织、待遇或技术转型，则应先究其本，不可仅以扩大征人代替军事改革。

## 事实与证据边界

- 韩国《兵役法》第三条规定，男子依法履行兵役义务，女子可自愿服现役及预备役；2023年宪法法院裁定现行规定合宪，并未判定女性不能服役。
- 2026年8月改革研究院民调支持女性征兵者为59.6%；该机构隶属改革党，样本1,006人，应答率2.3%，误差范围正负3.2个百分点。此为单次调查，不等于全民共识。
- 2026年10月，韩国国会重提女性征兵议题；兵务厅当时表示尚未正式考虑全面征兵，性别平等家庭部长随后表示应进行政策研究。二者均不等于政府已作出征兵决定。
- 韩国二十岁男性兵源预测及李在明总统选择服役方案，均按媒体报道口径陈述；选择服役方案为政策主张，不写作已实施制度。
- 2024年女性军人相关性骚扰及其他性暴力数字为举报件数；国防部称举报意愿提高亦影响数字，不将其等同于实际发生率。
- 挪威、瑞典经验仅用于说明男女皆可纳入征兵及按岗位选拔具有可行性，不据此断言韩国可以照搬。
