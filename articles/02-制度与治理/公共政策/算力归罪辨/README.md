## 论旨

以英伟达创始人黄仁勋2026年十一月受到的国会质询及公司董事会调查为发端，辨个人私德、商业合规、国家安全疑虑与公共政策责任不可互相代证。借曹操小斛、桑弘羊盐铁与嘉靖海贸诸事，论“借首安众”之政治诱因，但拒绝将历史类比冒充对当代个人罪行或政客动机的证明。主张既须据证查商，亦须查政府许可、电力成本分担及公共监管。

## 证据边界与校核

- 2026-11-04国会函为**要求闭门说明**，不是法院判决或正式认定泄密。
- 2026-11-08黄仁勋声明确认婚姻不忠；英伟达董事会同时表示目前无理由相信国家安全或公司秘密已遭损害，调查正在进行。
- H200相关**25%为进口关税**，不可据此称政府与企业已签秘密分赃协议。PJM的294亿美元是四轮容量竞价中数据中心负荷归因的累计容量费用，并非直接实缴居民账单。
- 个人或政客动机均属分析而非已核定事实；对华涉谍问题仅作为报道及国会疑虑陈述。
- 王垕之名见小说，曹操“小斛”事见《曹瞒传》引文；桑弘羊死因、汪直事迹与沈一石影视虚构均明确区分。
