## 篇旨与论证范围

本文追问：城乡户口性质统一之后，为何不同地区居民在公共服务与升学报名上仍可能面对不同规则？文章从1958年户口迁移限制、1984年自理口粮户口、1997—2001年小城镇改革、2014年城乡户籍统一，推至2024—2026年常住地公共服务改革；以北京、河南2027年高考报名政策为例，辨析户籍、学籍、居住地与分省招生计划之间的关系。

文章不把某一年度未经统一口径核实的录取率倍数作为论据，也不将地区差异简单归结为单一动机；重点区分报名资格、招生计划、教育资源与考生个人成绩。

## 主要依据

- 1958年《中华人民共和国户口登记条例》及2014年国务院户籍制度改革意见。
- 1984年国务院关于农民进入集镇落户的通知，以及清华大学中国新型城镇化研究院关于户籍改革阶段的研究。
- 教育法关于平等受教育机会的规定。
- 北京市、河南省2027年普通高招报名政策。
- 教育部2026年普通高校招生工作通知。
- 国务院2024年新型城镇化五年行动计划、2026年常住地提供基本公共服务实施意见。
