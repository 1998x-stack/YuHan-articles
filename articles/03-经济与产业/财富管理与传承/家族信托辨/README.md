## 篇旨与限度

从“以利逐富者却轻信陌生人护财”的反讽入手，以设问和正反论辨追究守财之难；并指出信托的真正价值不在假定受托人皆为君子，而在独立财产、法定职责、披露及救济。反对将家族信托当成万能避债工具或无风险理财。

原始问题的“坑蒙拐骗”仅作为**假设中的逐利失德者**的性格批评；不表示所有创业者或信托从业者均有违法行为。文中制度解释以中国大陆为讨论范围，引用监管规定和《信托法》，不构成个人法律或投资意见。

**重要区分**：按照银保监规〔2023〕1号，境内监管意义上的家族信托属于资产服务信托，初始设立实收信托应不低于人民币1000万元；它不等于所有俗称的“家庭财富规划”，更不等于保证本金或年度收益的产品。个案以实际适用规则和信托文件为准。
