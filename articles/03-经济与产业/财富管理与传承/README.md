# 财富管理与传承

**部类**：[03-经济与产业](../README.md)

讨论信托、资产托管、财富传承、委托代理、利益冲突与受托治理：一方面检验制度安排能否降低道德风险，另一方面辨别风险隔离、合规、税务与投资承诺的边界。

## 已刊作品

- [《家族信托辨》](家族信托辨/README.md)：不以陌生人之德作保，而以法律、契约、账目与问责建立可核验的信托。

## 归档边界

家族内日常伦理与亲子关系的议论可归“社会与人情”；宏观税制与公共财政归“财政与分配”；以财富持有、传承和受托制度为论证中心者归此。不得把商业宣传或无来源的增值率写成制度事实。
