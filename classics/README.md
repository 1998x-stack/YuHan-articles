## 原典与改写分流

- **`classics/`**：真实古文，文献出处与版本说明独立标注；保留文体、历史语境及作者本来的立场。
- **`articles/`**：现当代命题的韩愈式古文论辩创作，不可将其误署为韩愈本人。
- 网页从本目录 Markdown 生成，入口为 [GitHub Pages 古文原典](https://1998x-stack.github.io/YuHan-articles/classics/)。
- 每篇固定 `meta.json`（作者、原典文体、题名、原文文件名、出处），与原稿 `.md`、该篇 `README.md`（版本与异文）配套。

## 版本与版权

正文以古人公有领域作品为基础，参校公开的维基文库《全唐文》与《古文观止》条目。**简繁字形、标点、个别异文会因底本而不同**，本库不自称权威定本。页面上的文献元数据、编者导读与现代句读不属于韩愈原文；若需严格校勘，请核对逐篇外部底本与原典卷次。

为便于比较，不把译文、AI 补写、导读或自动生成的“原文补全”混入正文；发现异文时应在该篇 README 记录，并提供可复核来源。

原作进入公有领域，不等于第三方网站的现代编辑、注释或网页排版当然可以直接照搬。本仓库只保存古代作品及必要的来源归属，不复制现代翻译和页面注释。

## 更新约定

- 原稿 `.md` 的第一行是 `# 篇名`，其下为完整原文段落。
- `meta.json.status` 仅允许 `published` 或 `draft`；网站只展示 `published`。
- `meta.json.order` 决定选目顺序；其值在五篇中唯一。
- `meta.json.manuscript` 只能是同目录文件名，禁止路径穿越。
- 运行 `python3 -m unittest discover -s tests -p 'test_classics.py'` 与站点检查确保文件可读。
