# 韩愈式古文论辩写作

## 任务定位

不是白话逐字文言化，而是以韩愈古文的**立论、推理、诘辩与气势**重构文章。风格参照《原道》《师说》《讳辩》《争臣论》《答李翊书》《进学解》《杂说》等不同文体，借其方法，不伪托其言。

以“**义明、理密、辨深、辞健、法活、气贯、意远**”为验收准则。事实准确和论证完整，优先于辞采。

## 何时使用

- 用户说“按韩愈文风改写”“将评论改成唐代论辩古文”“提升古文论证与文气”等。
- 用户提供文章，希望**保留立场与证据**，但改造结构、语言和说理方式。
- 用户要求审校韩愈式文章的**论证、事实、文言表达**，可提供针对性修改；审校任务不必一律重写全文。

不应在纯翻译、无论证目标的诗歌、或用户明确指定其他文体时强行启动此风格。若用户未给原文却要求“改写”，先请其提供；若明确要求原创立论，可在其提供的题旨与可核实材料范围内撰写。

## 操作规程（分析在内部完成）

### 1. 抽取论旨与证据

内部用一句话确认“此文欲证明何事”。列出人物、年代、数字、行为、结果、关键因果，并区分：

- **事实**：原文确有陈述，保存出处归属与不确定性。
- **解释**：作者对事实的因果推断，须查验前提。
- **设论**：假设情境，须使用“使”“苟”“若”等标志。
- **评价**：道德或制度判断，须由前论支持。

不把原作者推测改写成确凿史实；不凭空创造史书、韩愈原话、数字或人物动机。

### 2. 找出需要回答的真正矛盾

识别通行观点与异常结果之间的张力。由现象追索近因，再追处境、利害、规则和风俗；不要以“小人贪利”一语代替机制分析。

主动提出**最强合理异议**。先承认对方成立的部分，再检验其必要前提；如有反例或条件限制，调整自己的结论，不能故作强辩。

### 3. 设计论证进程

通常依**立疑 → 据事 → 推原 → 设难 → 引申 → 断案**推进，必要时灵活合并。每段应增加证据、深化解释、破解异议、限定范围或完成判断之一。

使用实质性对照：古今、名实、言行、利害、前后果。对照对象须可比。每个反问必须引出新的推理，不得为激昂而无意义反问。

### 4. 以散体古文重写

- **散为本，骈为辅**：长短错综，节奏有张弛；避免四字排偶连篇。
- **虚词服务逻辑**：“夫”发端，“盖”申因，“然则”承推，“苟”“使”设条件，“何”“岂”立诘，“故”作结。
- **文气从理势来**：警句出于推论，不以典故、怒辞或奇字制造深刻。
- **兼顾古雅与精确**：现代科学、组织与制度概念宁可解释清楚，不强用失真的古语。
- **篇末回扣篇首之疑**：下判断而不过度扩大适用范围；不附会儒家道统。

### 5. 事实复核与七维审校

逐一检查数字、人物、时间、史料归属、推测和假设是否保持原意。删去仅有文采、对说理无贡献的句子。检查**义明、理密、辨深、辞健、法活、气贯、意远**，尤其纠正动机臆测、因果跳跃和个案泛化。

### 6. 严格遵守用户交付格式

默认只输出**一个古雅切题的篇名和连贯、可独立阅读的文言正文**。不要附上摘要、白话译文、论证提纲、修辞说明、评分或内部推理。若用户明确要求对照、注释、考据或 Markdown 文件，则按其要求提供相应附加材料。

## 内容保真红线

1. 不改变原文主要立场；必要时可补足推理，但不得强行植入另一套意识形态。
2. 不以获利即判虚伪；名实辨析须联系行为、效果与充分证据。
3. 不删去决定结论成立的数字、人物和具体事实。
4. 不将未经核查的传闻、寓言或拟设对话写成“史载”。
5. 不在材料不足时作普遍断言；事实存疑，论断亦当存限。
