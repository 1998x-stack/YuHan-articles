# 韩愈古文名篇的选篇与校阅

本仓库从韩愈原作中选取五篇：**《师说》《马说》（《杂说四》）《进学解》《原道》《祭十二郎文》**，用于示范从论说、短辨、设难、体系立论到抒情祭文的古文章法。选篇兼顾知名度与文体代表性，**不是可验证的权威排名**，也不宣称每篇都是纯粹议论文。

## 版本原则

- 正文来自唐代韩愈古文（公有领域），依公开的简体整理版本审读。现代注释或译文并未收入。
- 现代标点、分段和字形统一属于后世编辑行为，可能异于古籍原貌。
- 逐篇 `classics/<slug>/README.md` 标注参校网址和异文信息；不要把这些版本说明插入原作正文。
- 对《马说》说明其本题《杂说四》，通称《马说》，并说明“祗／祇／衹”等不同文字；对《进学解》的个别古字采用通行字形。
- 《原道》对佛、老的强烈批评及历史叙述系作者特定时代的观点；收录为史料与文学文本，不视为本站现代编辑立场。
- 《祭十二郎文》为悼念家人的祭文，入选在于展示韩愈散体古文中情感与节奏的表现，非以论辩归类。

## 校对与内容边界

每篇正文存于 `classics/<slug>/<篇名>.md`；元数据 `meta.json` 记录作者、朝代、文体、出处及网页选目顺序。页面由 `scripts/build_site.py` 转为 HTML，文章表层和原典层分开处理。

如需严谨校勘，建议对照具体卷次与文字异同逐句整理校记；此版旨在便于公众阅读，不主张已经完成所有古籍版本的逐字校勘。引述本项目原典内容时，请同时保留韩愈作者署名与对应版本记录。
