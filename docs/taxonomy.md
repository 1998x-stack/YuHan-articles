# 八部分类与内容归档规则

## 设计原则

1. **一级依题旨**：按主要论证对象归入固定八部，而非按古文题式“论、辨、原”分类。
2. **二级依问题域**：相近问题设子目，不为每篇文章临时新开一级类。
3. **三级一篇一档**：每篇目录有导读 `README.md`、`article.json`、正文 Markdown，以及对应 DOCX/PDF。
4. **唯一主类，允许多标签**：跨领域作品选择论证重心作为唯一主类；其他主题写入 `topics`。
5. **占位而不造假**：无稿件的子目仅设说明页；禁止用虚构篇名、空 Markdown 冒充已出版文章。
6. **保持历史与现代的证据边界**：名实之辨必须检验事实，现代统计与史料标明来源，不能用文采代替证明。

## 典型归类

| 主题 | 推荐位置 | 理由 |
| --- | --- | --- |
| 后发优势、居民收入、产业结构 | `03-经济与产业/增长与分配/` | 增长成果与分配是核心论题 |
| 纪委借调、执纪程序 | `02-制度与治理/纪检监察/` | 行政监督权责与程序是主线 |
| 河伯娶妇一类巫俗辨析 | `04-宗教与风俗/巫俗与信仰/` | 论证重点为信念、恐惧与利益机制 |
| 寺观收费、宗教机构财务 | `04-宗教与风俗/宗教组织/` | 论证对象为宗教组织治理 |
| 养老金制度与代际负担 | `05-社会与人情/养老与保障/` | 主要问题为养老保障公平 |
| 韩愈式论辩章法与写作技法 | `07-文论与写作/论辩修辞/` | 研究对象为写作方法 |

上表为**后续稿件的归类建议**，不表示其中所有题目已经出版。

## 扩展原则

新增子目时，须先检验现有子目是否足以收录；确需新增，则在目标一级目录下创建解释收录范围的 `README.md`，修改父级目录、`articles/README.md` 和本分类文档。新增一级分类应极为审慎，并为其预留两位序号。
