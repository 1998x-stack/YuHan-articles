# 版权、资料来源与使用许可

> 此文说明仓库不同内容的权利边界，并**不自行赋予任何第三方材料的转载授权**。

## 1. 公开可读与许可证的区别

GitHub 上可访问的仓库不等于所有文本、代码、图片和字体均自动处于公有领域，也不等于默认采用 MIT、Apache-2.0、CC BY 等特定许可证。

**如仓库根目录没有正式 LICENSE**，不要推定整体代码与现代文章已授予某种开源或开放内容许可。要选择统一许可证，应由仓库权利人确认代码、生成稿件和可能含他人内容的权属，再分别确定适用协议。本文不替维护者选择许可证，也不改变既有作品的法定权利。

## 2. 作品类别

| 类别 | 原则 |
| --- | --- |
| 韩愈唐代古文原作 | 原作者作品属于公有领域，可就古代原作进行研究、引用和整理 |
| 现代编者的标点、译注与校勘 | 不应因为所校古文公有领域就假定所有现代整理成果无权利限制 |
| 现代仿韩文章 | 权利归属视原作者、所依据资料和具体创作贡献而定 |
| 史料、统计、新闻、网页图片 | 按来源的实际权利与引用许可处理 |
| 程序、Prompt、Skill、网站 CSS | 公开可见不等于当然有可再分发的开源许可；须以有效 LICENSE 为准 |
| 字体二进制 | 必须核验再分发、嵌入与商用条款，不上传来源不明字体 |

## 3. 原文改写与公共讨论

要把现代文章或网页长文收录进 `articles/`，应取得足够的授权或仅在合法范围内引用必要片段。引用须标明出处和性质。不得为“使仓库内容完整”而自动抓取受版权保护的全文，也不得把原文逐字复制后仅换成繁体或古字当作独立创作。

讨论经济、公共治理、宗教、法律等现实时事时，来自公开政府文书、新闻报道和受访者口述的事实仍须核查时间、口径与归属；如存在引用界限和版权疑问，应在逐篇 README 说明。

## 4. 原典的版本要求

`classics/` 中韩愈的公有领域正文与现代编辑记录分开管理；逐篇 meta.json、README 明示版本与来源链接。不得不加判断地整段搬用第三方网页的现代译注、鉴赏、署名编辑稿。

《马说》又见《杂说四》、字形与现代句读可能存在多个通行版本；遇到异文时应记录底本、所选文字与理由，不把统一标点误称为完成所有版本校勘。

## 5. PDF/DOCX 与字体

生成的 PDF/DOCX 由同一 Markdown 正文派生，但文件格式不同不意味着取得新的原文版权。PDF 可嵌入字体时优先选择许可证允许的本地字库；缺失字体时使用 ReportLab 非嵌入 CID 回退，不应绕过字库许可。

详细设置：[字体与授权](fonts.md) 与 [出版约定](article-archive-conventions.md)。

## 6. 合规处理与建议

新贡献须声明自己有权提交相应现代文本和素材，不将私人文稿、未经许可的附件或受保护的整篇原文上传到公共仓库。对于存疑内容，应先明确来源、权利人与计划使用方式再公开。

本文件是项目维护政策，不是针对具体案件的法律意见。今后如果权利人确定适当的 LICENSE，应同步更新根级 README、CONTRIBUTING、网站页脚和对应素材说明。
