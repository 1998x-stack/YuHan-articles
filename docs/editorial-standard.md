# 编辑与学术审校标准 · Editorial Standard

## 目标

以韩愈古文的**立论之法**而不是表面文言词汇重构现代文章：以思想统摄辞句，以证据支持论断，以强异议检验结论。编辑范围分**现代仿韩文**与**韩愈本人原典**，不得混同。

## 现代论说文的编辑流程

1. **识别问题**：一句话确定核心论点与拟解释的矛盾。若不能明确，先审题。
2. **建立证据清单**：将材料分成事实、直接引文、二手转述、作者推测、假设案例、价值判断。为数字记录时点、统计口径与来源。
3. **比较论证路径**：考虑由现象入手的因果推究与由流俗成见入手的反驳路径，选最能推进论旨的一种。
4. **构造最强反对意见**：先准确陈述其有效部分，再依前提、逻辑和证据辨其边界；禁止稻草人式反驳。
5. **重构古文**：以散体为主，排比为辅；长短有变，虚词有逻辑。每段要有论证功能，不能因文采华丽而离题。
6. **名实复核**：公开宣称、实际行动、后果与获利四者分别讨论；“从中获利”不等于“全然虚伪”。
7. **审校成篇**：篇首迅速立疑，篇中逐层设难，篇末由证据作出有边界的判断。

## 证据与事实层级

| 类别 | 可以如何使用 | 不可如何使用 |
| --- | --- | --- |
| 史籍直接记载 | 明示出处、篇名与文中事实 | 伪造古籍原句或添人物内心 |
| 官方/原始统计 | 明示时间与口径，解释范围 | 混用年份、国家、币值和基准 |
| 采访/个人见闻 | 明示受访者、转述、未核验范围 | 写成全社会普遍事实 |
| 作者推测 | 使用“或”“盖”“殆”等有分寸表达 | 改写成“史载”“已证实” |
| 假设推演 | 标明“使”“若”“苟”条件 | 当成发生过的真实事件 |
| 道德评价 | 以事实和标准为依据明确立场 | 凭情绪或时代身份代替证明 |

重要现代议题涉及司法、宗教、养老金、经济或国际情势时，时间、机构、法律条文、数字与引用在出版前需要逐项核查。**自动化测试无法履行事实核查义务。**

## 韩愈式章法检查

- **推原究本**：是否由表及里，解释动机、激励与结构，而不止贴标签？
- **反俗立论**：是否公平呈现对方说法及其最强依据？
- **设难诘问**：每一设问是否对结论有推进作用？
- **辨名核实**：名称与实效的背离是否有证据？
- **正反互证**：对立标准是否在同一条件下对比？
- **由事推理**：从个案引申到一般认识是否有足够边界？
- **蓄势断案**：终论是否由前文生发，未越出所证范围？

逐篇依 [七维质量量表](quality-rubric.md) 复核：义明、理密、辨深、辞健、法活、气贯、意远。对于证据不足者允许退稿或明确“待核”，不靠删掉限定语换取文章气势。

## 韩愈原典的独立规则

`classics/` 只收韩愈原文，不收当代仿作、AI 扩写或未经核实的“韩愈佚文”。古文可能有不同古籍版本，简繁、字形、句读及通称并不完全统一；任何字句修改须记录改前、改后、底本及依据。

文内不要以编者意见改造韩愈的时代思想；如需现代批评或语境解释，写在逐篇 README 或独立研究文章，而非混入原作 Markdown。见 [原典版本规范](classic-editions.md)。

## 来源和版权

韩愈唐代作品公有领域不意味着近现代学者的译文、标点整理、校注、图片或排版当然不受保护。文献出处必须清楚；引用现代材料须评估授权与合理引用。见 [权利说明](rights-and-licenses.md)。

## 审稿门槛

提交前至少确认：作者归属正确；核心结论被证据支持；史料与推测可分辨；无伪造引语和数据；古文句法可通读；原文立场未被强改；交叉归类不重复全文；Markdown 第一行题目与元数据一致。技术验证由 [维护手册](maintainer-runbook.md) 的命令执行，文学与史料质量仍需人工复审。
