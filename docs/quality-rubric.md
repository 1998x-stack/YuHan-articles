# 七维质量评估

本项目的审稿量表为**人工质检参考**，不是已经完成的自动风格检测。每维 0—3 分：0 缺失或错误，1 仅有表象，2 基本成立，3 充分且自然。满分 21 分。

| 维度 | 3 分表现 | 常见缺陷 |
| --- | --- | --- |
| **义明** | 开篇之疑与全文主张清晰 | 主题数次更换，最终没有判断 |
| **理密** | 前提、证据、推理、结论相承 | 情绪性断语或因果倒置 |
| **辨深** | 能解释表面说法所不能解释之处 | 只有道德指责，没有机制分析 |
| **辞健** | 雄健、奇崛、峭拔且通达 | 生僻词堆砌、套用古文口气 |
| **法活** | 条件、诘问、正反、骈散各司其职 | 句式复制、排比空转 |
| **气贯** | 段段推进，首尾互照 | 论证碎裂、警句堆积 |
| **意远** | 有普遍启发而结论有边界 | 个例上升为无证据的普遍断言 |

## 硬性质量门槛

以下问题不以高分抵消，出现即应退回修改：

- 凭空增添事实、年代、人物、数字或所谓“史书引文”；
- 把推测或假设写成确定事实；
- 偷换原作者的中心立场；
- 从某人获益直接推出其言行必然虚伪；
- 省略关键证据导致核心结论失去支撑；
- 以白话词序机械添加文言虚词，致使意义不明。

## 建议审稿顺序

先审**事实与结论边界**，再审**因果及反方论证**，最后审**语言、文气、节奏**。如果文气雄健而理据不实，必须优先改理。篇末应回答篇首之疑，不应再发无由之感叹。

## 快速自检

可以内部问七句：本文所争何事？凭何事实？何以如此？异议最强为何？何处名实相背？何处论势转折？结论可推至何处而止？

如有一问答不出，就不能仅凭辞采宣称文章已成。
