# 方法与证据规范

本文件说明如何把“韩愈之气”建立在“韩愈之法”上。以原文思想为纲，以实证与推理为骨。

## 一、先问原文到底在回答什么

审稿时先写出一条内部命题：“本文要说明的不是甲，而是乙；因为丙、丁、戊。”如不能写出，说明论题尚未凝聚。

提炼四类信息：

| 类别 | 作用 | 写作处理 |
| --- | --- | --- |
| 已述事实 | 构成论证的观察和材料 | 保存时间、人物、数字、因果过程及归属 |
| 原作者解释 | 说明事实为何发生 | 分解成可检验的中间推断 |
| 假设条件 | 检验不同解释的预期结果 | 以“苟”“使”“若”等显明为设论 |
| 规范判断 | 评判是非与得失 | 由此前事实与论证自然生发 |

只凭一方叙述的事件应维持相应的不确定性；“有材料记载”不等于“事实已无争议”。

## 二、从表面矛盾到深层原因

宜依次问：

1. **现象**：发生了什么？何处不合通常解释？
2. **近因**：何种行为直接导致这一结果？
3. **动因与处境**：当事者受到何种激励、约束、风险或预期影响？
4. **结构**：什么规则、权力关系或风俗使此行为反复出现？
5. **反证**：若另一解释为真，应见何种现象？现有材料支持吗？
6. **边界**：结论对何种人、何种条件、何种范围成立？

注意区分**发生的机制**与**人物主观目的**。由结果可以倒推可能机制，却不能不加证据地认定行为者必有某种恶意。

## 三、对反方意见公平而锋利

反驳须先立其最强版本。例如，若对方主张某制度“可使人勤学”，应先承认督促可能带来行动，再考察“被记录的行动”是否等于“真实的学习”，查证指标与目标是否同一。这样反驳的是论证漏洞，而不是想象中的愚人。

善用条件递进：“使甲真，则宜见乙；今所见反为丙。然则甲不足以尽释其事。”但也要考虑其他可能条件，避免把证据不足伪装成逻辑必然。

## 四、历史与现实材料的处理

- 数字、日期、人名、机构名与引文必须来自原文或已核验资料。
- 作者观点不能假装成古籍原话；引用古书时要核准文本与出处。
- 传说、寓言、作者拟言、史载事实分别标示，不得互相混淆。
- 某事件的后果不能直接证明某人动机；动机判断需要独立支持。
- 对争议来源宜用“某书载”“或谓”“未可遽定”一类相称语气。
- 如用户要求时事调查，应先核验来源；找不到证据时写明资料边界或保留存疑，不得制造数字与“官方通报”。

## 五、修辞须为论证服务

**设问**要揭出问题，**排比**要列出相互独立的根据，**对比**要保持可比标准，**警句**要自然归纳前文所得。凡不能推进论证的华辞，一概可删。

## 六、重写后逐句检查

每个断言都可追问：“原文或可信材料支持否？”每个反问都可追问：“是否引出新证或新理？”每个段落都可追问：“若删去，推论是否仍成立？”如果全删无损，说明它只是装饰。
